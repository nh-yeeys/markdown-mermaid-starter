# 学生作业：用 Markdown 和 Mermaid 解释系统

欢迎来到这个作业。你将把一个主题整理成清晰的结构化内容，用它向 LLM 提问，再批判性地阅读回答、核对资料并画出流程图。

本仓库提供了作业模板和提交前检查。你可以在 Codespaces 中完成、检查并提交全部工作。

## 从这里开始

1. 在 Codespaces 中打开本仓库。
2. 打开 [`submission.md`](submission.md)，把水循环示例改写成自己的主题和答案，不要只保留示例文字。
3. 在下方主题中选一个，也可以提出自选主题并获得教师批准。

不要提交个人隐私信息。遵守学校关于使用 AI 的规定，并标明哪些内容来自 LLM。

在 Codespaces 中可以打开 Copilot Chat 请它辅导你。本仓库已配置中文教学模式：Copilot 会提问、给提示并解释原因，帮助你自己完成作业，而不是替你编造答案。例如可以说：

- “请检查主题是否适合画流程图，但不要替我完成。”
- “请指出结构化简介中缺少的内容，并给出下一步提示。”
- “请检查 Mermaid 图的具体语法问题，不要直接替换整张图。”
- “请检查提示词是否明确说明读者、目标、背景、限制和输出形式。”
- “请指出 LLM 回答中需要核实的说法，并说明怎样寻找可靠来源。”

## 主题建议

选择一个你能准确解释的小型系统。好的流程图应有明确的起点、若干步骤，以及至少一个判断或结果。

- **校园生活：** 学生如何借阅图书、加入社团，或向辅导室寻求帮助。
- **社区服务：** 公共图书馆如何借出资料、食物银行如何分发捐赠物，或本地回收项目如何分类物品。
- **科学过程：** 植物如何生长、水处理厂如何净化水，或日食如何发生。
- **数字服务：** 密码重置如何进行、群聊消息如何送达，或推荐内容如何产生。请使用虚构示例，不要分享账户信息。
- **生活决策：** 如何筹办低废弃物校园活动、为出行选择交通方式，或为恶劣天气做准备。

## 提交作业

在 Codespaces 顶部菜单选择“终端 > 新终端”，再运行：

```sh
npm run check:submission
```

修正中文提示后再次运行，直到看到：

```text
作业检查通过（submission.md）。
```

检查可能提示缺少章节、保留了方括号提示、仍是示例、缺少来源链接或 Mermaid 语法无效。自动检查只验证格式和语法，不代表内容准确、来源可靠或已经获得评分。

在 VS Code 左侧打开“源代码管理”，确认要提交的文件包含作业，输入提交说明，再点击“提交”和“同步更改”或“推送”。也可以在终端运行：

```sh
git add submission.md
git commit -m "完成 Markdown 和 Mermaid 作业"
git push
```

如果提交、推送、检查或其他技术步骤失败，请先复制完整错误提示，把它贴给 Copilot，并说明你在做什么。可以直接说：“请先阅读这个错误，不要修改我的作业或运行任何可能覆盖内容的命令；先解释原因，再一步一步指导我解决。”

Copilot 会保留作业内容，优先选择不会强制覆盖远程仓库的解决方法。遇到冲突时，它会解释冲突标记和可选处理方式，并让你确认再继续，不直接替你决定保留或删除作业内容。

推送后，在仓库的 **Actions** 页面查看**检查作业**。绿色通过表示自动检查成功；红色失败表示需要修正后再次提交。除非教师另有说明，以截止时间前最近一次推送为准。

## 自动检查范围

- `submission.md` 中的必需章节存在且已填写。
- 至少有一张 Mermaid 代码围栏图表，且语法有效。
- LLM 回答部分包含至少一个 Markdown 来源链接或网址。

自动检查不会评价事实是否准确、来源是否可靠、图表是否有用，也不会判断学生是否认真分析了 LLM 回答；这些需要教师人工评阅。
